Shopping Bill Calculator 🛒

This Python project calculates the total bill for multiple items entered by the user and applies a discount based on the total purchase amount.

The program first asks the user to enter the number of items. Then it takes the price of each item using a loop and calculates the total bill. After calculating the total, the program checks if the user is eligible for a discount.

If the total amount is ₹1000 or more, a 20% discount is applied.
If the total amount is ₹500 or more, a 10% discount is applied.
If the total amount is less than ₹500, no discount is given.

Finally, the program displays:

Total bill amount

Discount applied

Final bill amount after discount

This project demonstrates the use of loops, conditional statements, user input, and basic arithmetic operations in Python.
